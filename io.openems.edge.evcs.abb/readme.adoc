= ABB Terra AC Charging Station

This component implements the ABB Terra AC charging station. It collects all relevant information into the given Nature Channels and its own Channels and sends charging commands that have been set by another controllers.

=== Technical Data

Implemented Natures:
* Evcs (Electric Vehicle Charging Station)
* ManagedEvcs
